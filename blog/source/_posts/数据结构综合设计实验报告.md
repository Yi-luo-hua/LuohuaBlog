## 三种排序算法

{% tabs sort_tabs %}

<!-- tab 快速排序 -->

```c
void QuickSort(Student arr[], int left, int right) {
    if (left >= right) return;
    float pivot = arr[left].total;
    int i = left, j = right;
    while (i < j) {
        while (i < j && arr[j].total <= pivot) j--;
        if (i < j) arr[i++] = arr[j];
        while (i < j && arr[i].total >= pivot) i++;
        if (i < j) arr[j--] = arr[i];
    }
    QuickSort(arr, left, i - 1);
    QuickSort(arr, i + 1, right);
}
```

{% label 时间复杂度 blue %} O(n log n) 平均，O(n²) 最坏，不稳定

<!-- tab 归并排序 -->

```c
void MergeSort(Student arr[], int left, int right) {
    if (left >= right) return;
    int mid = (left + right) / 2;
    MergeSort(arr, left, mid);
    MergeSort(arr, mid + 1, right);
    Merge(arr, left, mid, right);
}
```

{% label 时间复杂度 blue %} O(n log n)，稳定

<!-- tab 冒泡排序 -->

```c
void BubbleSort(Student arr[], int n) {
    for (int i = 0; i < n - 1; i++) {
        int swapped = 0;
        for (int j = 0; j < n - 1 - i; j++)
            if (arr[j].total < arr[j + 1].total) {
                Swap(&arr[j], &arr[j + 1]);
                swapped = 1;
            }
        if (!swapped) break;
    }
}
```

{% label 时间复杂度 blue %} O(n²)，稳定

{% endtabs %}

# 实验二：长整数四则运算

## 问题描述

计算机内置类型有范围限制（`long long` 最大约 9×10¹⁸），超出此范围需自定义数据结构完成运算。

{% note danger %}
本实验的核心挑战在于**进位/借位的链式传播**以及**任意精度的精确计算**。
{% endnote %}

## 实验要求

{% checkbox checked, 任意长整数的加法、减法，乘除可选做 %}
{% checkbox checked, 进位、借位正确处理 %}
{% checkbox checked, 按中国习惯每四位一组分隔显示 %}

## 数据结构：双向循环链表

```c
typedef struct Node {
    int data;            // 四位数字（0~9999）
    struct Node *prev;
    struct Node *next;
} Node;

typedef struct {
    Node *head;          // 头结点
    int sign;            // 符号位
    int length;
} LongInt;
```

{% tip info %}
如 `1,0000,0000,0000` 表示为三个结点，分别存储 `1`、`0`、`0`。
{% endtip %}

## 核心算法

{% folding blue, 加法算法 %}

1. 对齐两个长整数结点（从低位向高位）
2. 逐结点相加，处理进位 `carry`
3. 最高位若有进位则创建新结点

```c
LongInt* Add(LongInt *a, LongInt *b) {
    LongInt *result = (LongInt*)malloc(sizeof(LongInt));
    InitLongInt(result);
    Node *pa = a->head->prev, *pb = b->head->prev;
    int carry = 0;
    while (pa != a->head || pb != b->head || carry) {
        int va = (pa != a->head) ? pa->data : 0;
        int vb = (pb != b->head) ? pb->data : 0;
        int sum = va + vb + carry;
        carry = sum / 10000;
        InsertHead(result, sum % 10000);
        if (pa != a->head) pa = pa->prev;
        if (pb != b->head) pb = pb->prev;
    }
    return result;
}
```

{% endfolding %}

{% folding green, 减法算法 %}

```c
LongInt* Subtract(LongInt *a, LongInt *b) {
    LongInt *result = (LongInt*)malloc(sizeof(LongInt));
    InitLongInt(result);
    Node *pa = a->head->prev, *pb = b->head->prev;
    int borrow = 0;
    while (pa != a->head || pb != b->head) {
        int va = (pa != a->head) ? pa->data : 0;
        int vb = (pb != b->head) ? pb->data : 0;
        int diff = va - vb - borrow;
        if (diff < 0) { diff += 10000; borrow = 1; }
        else borrow = 0;
        InsertHead(result, diff);
        if (pa != a->head) pa = pa->prev;
        if (pb != b->head) pb = pb->prev;
    }
    TrimZeros(result);
    return result;
}
```

{% endfolding %}

|------|------|

# 实验三：哈夫曼编码/译码器

## 问题描述

利用哈夫曼编码进行信息通信可提高信道利用率。设某编码系统共有 n 个字符，使用频率分别为 {w1, w2, …, wn}，设计不等长编码方案使空间效率最好。

{% note info %}
核心思想：**频率高的字符用短编码，频率低的用长编码**，使加权路径长度最短。
{% endnote %}

## 实验要求

{% checkbox checked, 从终端读入字符集大小 n 及 n 个字符和权值，建立哈夫曼树 %}
{% checkbox checked, 利用已建好的哈夫曼树对正文进行编码和译码 %}
{% checkbox checked, 打印编码表和哈夫曼树结构 %}

## 系统流程

{% image /img/huffman-flowchart.png, alt=哈夫曼编码/译码系统流程图 %}

## 数据结构

```c
typedef struct {
    int weight;   // 权值
    int parent;   // 双亲下标，-1 表示无
    int lchild;   // 左孩子下标，-1 表示无
    int rchild;   // 右孩子下标，-1 表示无
} HTNode;

typedef char** HuffmanCode;
// HC[i] 为第 i 个字符的哈夫曼编码

char chars[MAXN];
int  freq[MAXN];
```

由于哈夫曼树共有 {% span red, 2n-1 %} 个结点（n-1 次合并），数组长度为 2n-1。

## 核心算法

### Select 函数

```c
void Select(HTNode HT[], int n, int *s1, int *s2) {
    int min1 = INT_MAX, min2 = INT_MAX;
    *s1 = *s2 = -1;
    for (int i = 0; i < n; i++) {
        if (HT[i].parent == -1) {
            if (HT[i].weight < min1) {
                min2 = min1; *s2 = *s1;
                min1 = HT[i].weight; *s1 = i;
            } else if (HT[i].weight < min2) {
                min2 = HT[i].weight; *s2 = i;
            }
        }
    }
}
```

### 编码生成

{% tip info %}
- 从叶子回溯到根：左孩子 → 编码 `0`，右孩子 → 编码 `1`
- 将路径字符串**逆序**即为该字符的哈夫曼编码
{% endtip %}

### 译码

从根出发：读 `0` 走左孩子，读 `1` 走右孩子，到达叶子则输出字符并回到根。

<!-- tab 共同收获 -->

1. **数据结构的选型**直接影响算法效率

3. 树结构在***最优编码***问题上有天然优势
4. 边界条件处理是工程实现的核心
