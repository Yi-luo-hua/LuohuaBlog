这份笔记整理了**矩阵快速幂**在图论中的**三大核心变体**。

只要掌握了 **“广义矩阵乘法”** 的定义，你就可以通过修改 `mul` 函数中的两行代码，解决 90% 的固定步数图论题。

---

> **核心原理**：矩阵乘法不仅仅是“乘法和加法”。
> 只要满足**结合律**的运算系统（半环结构），都可以套用矩阵快速幂。
>
> **通用公式**：$C_{ij} = \bigoplus_{k} (A_{ik} \otimes B_{kj})$
> *   $\otimes$ (内层运算)：对应一步的转移（如：累加代价、计算概率、连通检查）。
> *   $\bigoplus$ (外层运算)：对应状态的聚合（如：取最小值、求和、取或）。

---

## 1. 基础计数版 (Path Counting)
**应用场景**：求从 $S$ 到 $T$ **恰好经过 $K$ 步**的方案数。
**典型例题**：[洛谷 P3758 [TJOI2017] 可乐](https://www.luogu.com.cn/problem/P3758)

*   **内层运算 ($\otimes$)**：乘法 `*` (分步原理)
*   **外层运算 ($\bigoplus$)**：加法 `+` (分类原理)
*   **单位矩阵 ($I$)**：对角线为 1，其余为 0。
*   **注意**：通常需要取模。

```cpp
const int MOD = 1e9 + 7;

// C[i][j] = sum(A[i][k] * B[k][j])
Mat mul(const Mat &A, const Mat &B) {
    Mat C(N, vector<ll>(N, 0)); // 初始化为 0
    for (int i = 0; i < N; i++) {
        for (int k = 0; k < N; k++) {
            if (A[i][k] == 0) continue; // 剪枝
            for (int j = 0; j < N; j++) {
                // 标准矩阵乘法 + 取模
                C[i][j] = (C[i][j] + A[i][k] * B[k][j]) % MOD;
            }
        }
    }
    return C;
}

// 快速幂
Mat mpow(Mat base, ll exp) {
    Mat res(N, vector<ll>(N, 0));
    for (int i = 0; i < N; i++) res[i][i] = 1; // 单位矩阵：对角线为 1
    while (exp) {
        if (exp & 1) res = mul(res, base);
        base = mul(base, base);
        exp >>= 1;
    }
    return res;
}
```

## 2. 最短路/最长路版 (Min-Plus / Max-Plus)
**应用场景**：求从 $S$ 到 $T$ **恰好经过 $K$ 步**的最小/最大权值和。
**典型例题**：[AtCoder F - Exactly K Steps 2](https://atcoder.jp/contests/abcxxx/tasks/abcxxx_f)

*   **内层运算 ($\otimes$)**：加法 `+` (路径长度累加)
*   **外层运算 ($\bigoplus$)**：取最值 `min` / `max` (择优)
*   **单位矩阵 ($I$)**：
    *   **Min版**：对角线为 0，其余为 `INF`。
    *   **Max版**：对角线为 0，其余为 `-INF`。

```cpp
// 最短路版本
const ll INF = 4e18; 

// C[i][j] = min(A[i][k] + B[k][j])
Mat mul(const Mat &A, const Mat &B) {
    Mat C(N, vector<ll>(N, INF)); // 初始化为 INF
    for (int i = 0; i < N; i++) {
        for (int k = 0; k < N; k++) {
            if (A[i][k] == INF) continue; // 必须剪枝
            for (int j = 0; j < N; j++) {
                if (B[k][j] == INF) continue;
                C[i][j] = min(C[i][j], A[i][k] + B[k][j]);
            }
        }
    }
    return C;
}

// 快速幂
Mat mpow(Mat base, ll exp) {
    Mat res(N, vector<ll>(N, INF));
    for (int i = 0; i < N; i++) res[i][i] = 0; // 单位矩阵：对角线为 0
    while (exp) {
        if (exp & 1) res = mul(res, base);
        base = mul(base, base);
        exp >>= 1;
    }
    return res;
}
```

## 3. 连通性版 (Reachability / Boolean)
**应用场景**：问从 $S$ 出发走 **恰好 $K$ 步** 能否到达 $T$。
**典型例题**：[POJ 3613 (变形)](http://poj.org/problem?id=3613)

*   **内层运算 ($\otimes$)**：逻辑与 `&` (必须有路)
*   **外层运算 ($\bigoplus$)**：逻辑或 `|` (任意一条通即可)
*   **单位矩阵 ($I$)**：对角线为 1 (True)，其余为 0 (False)。
*   **优化**：可以使用 `std::bitset` 将复杂度从 $O(N^3 \log K)$ 降至 $O(\frac{N^3}{64} \log K)$。

```cpp
// C[i][j] = OR(A[i][k] AND B[k][j])
Mat mul(const Mat &A, const Mat &B) {
    Mat C(N, vector<ll>(N, 0)); // 初始化为 False (0)
    for (int i = 0; i < N; i++) {
        for (int k = 0; k < N; k++) {
            if (!A[i][k]) continue; // 剪枝
            for (int j = 0; j < N; j++) {
                // 只要有一条路通，则通
                if (B[k][j]) C[i][j] = 1; 
                // 或者写成: C[i][j] = C[i][j] | (A[i][k] & B[k][j]);
            }
        }
    }
    return C;
}

// 快速幂
Mat mpow(Mat base, ll exp) {
    Mat res(N, vector<ll>(N, 0));
    for (int i = 0; i < N; i++) res[i][i] = 1; // 单位矩阵：对角线为 1
    while (exp) {
        if (exp & 1) res = mul(res, base);
        base = mul(base, base);
        exp >>= 1;
    }
    return res;
}
```

## 4. 高级变形技巧 

### 技巧 A： "不超过 K 步"
如果题目问的是“**K 步以内**（1 到 K 步）到达的最短路/方案数”，怎么做？

**方法：拆点法 / 0权边法**
*   **方案数**：给每个点加一个**自环** `i -> i`，权值为 1。这意味着你可以选择“原地不动”（浪费一步）。
*   **最短路**：给每个点加一个**自环** `i -> i`，权值为 0。这意味着“原地不动不花钱”。
*   **效果**：$G^K[S][T]$ 直接包含了走 $1, 2, ..., K$ 步的所有最优情况。

### 技巧 B： "点权" 转 "边权"
如果题目给的是经过每个**点**有花费，而不是边？
*   **方法**：拆点。将点 $u$ 拆成入点 $u_{in}$ 和出点 $u_{out}$。
*   $u_{in} \to u_{out}$ 连边，权值为该点权值。
*   原图边 $u \to v$ 变为 $u_{out} \to v_{in}$，权值为 0（或原边权）。

### 技巧 C： 只有 $K$ 很小，$N$ 很大？
如果 $K \le 10^9$，$N \le 10^5$，但是图是**稀疏**的（边数 $M$ 很少）？
*   不能用 $O(N^3)$ 矩阵。
*   **方法**：倍增法 (Binary Lifting)。
*   `dp[k][u]` 表示从 $u$ 走 $2^k$ 步到达的点/代价。

## 5. 总结速查表 (Cheat Sheet)

| 问题类型 | 初始化 (Mat C) | 循环内更新逻辑 | 单位矩阵 (I) |
| :--- | :--- | :--- | :--- |
| **路径计数** | 全 0 | `C += A * B % MOD` | 对角线 1，余 0 |
| **最短路** | 全 INF | `C = min(C, A + B)` | 对角线 0，余 INF |
| **最长路** | 全 -INF | `C = max(C, A + B)` | 对角线 0，余 -INF |
| **可达性** | 全 0 (False) | `C = C | (A & B)` | 对角线 1，余 0 |
| **概率/期望** | 全 0.0 | `C += A * B` | 对角线 1.0，余 0.0 |
