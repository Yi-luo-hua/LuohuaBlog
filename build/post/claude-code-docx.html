场景

今天在手机上完成了一次完整的文档修改工作流：一份数据库实验报告需要做格式规范化，通过Claude Code直接在手机上操作.docx文件，经过两轮迭代修改，最终达到提交标准。

整个过程全部在手机上完成：接收文件→解压XML→Claude分析修改→打包→发送回微信。全程没有打开电脑上的Word，甚至没有离开聊天界面。

任务背景

手头有份《数据库原理及应用 实验二》的实验报告，上一轮已经改过主要问题（NVARCHAR、N前缀、触发器集合写法、权限管理），但还有几处格式细节需要打磨：

序号 位置 问题
1 第（二）1 存储过程 GO放在了注释后面
2 第（二）2 存储过程 WHERE子句缺少分号
3 第（四）1 安全管理 CREATE LOGIN后缺GO
4 第（四）3 授权 GRANT前缺USE/GO

修正过程

第一轮：四个格式问题

1. GO从注释后移到END;之后

修改前：

END;

-- 调用示例：
GO
EXEC 查询指定年龄学生 @年龄 = 20;

修改后：

END;
GO

-- 调用示例：
EXEC 查询指定年龄学生 @年龄 = 20;

2. WHERE子句补分号

WHERE 学生.所在系 = @系名 → WHERE 学生.所在系 = @系名;

3. CREATE LOGIN后加GO，USE后加GO

CREATE LOGIN u1 WITH PASSWORD = '123456', CHECK_POLICY = OFF;
CREATE LOGIN u2 WITH PASSWORD = '123456', CHECK_POLICY = OFF;
CREATE LOGIN u3 WITH PASSWORD = '123456', CHECK_POLICY = OFF;
GO

USE StudentsXXXX;
GO

CREATE USER u1 FOR LOGIN u1;

4. GRANT前补USE StudentsXXXX + GO

USE StudentsXXXX;
GO

GRANT SELECT ON 课程 TO u1;
GRANT SELECT ON 选课 TO u1;
GRANT INSERT ON 课程 TO u2;
GO

第二轮：两个小细节

第一轮改完后审查，又发现两个可优化的地方：

1. 存储过程内部语句补分号

PRINT N'年龄错误';   -- 补分号
WHERE 年龄 = @年龄;   -- 补分号

2. 四.5节点USE后加GO

USE StudentsXXXX;
GO  -- 新增

GRANT CREATE TABLE TO u3;
GRANT ALTER ON SCHEMA::dbo TO u3;
GO

技术原理

很多人不知道：.docx文件本质上是一个ZIP压缩包，里面是一堆XML文件。所以可以直接解压→改XML→打包回去，完全不需要Word。

解压：

python unpack.py 报告.docx unpacked/

解压后得到word/document.xml等15个XML文件。

编辑XML： 直接对document.xml做字符串替换：

<!-- 补分号：修改 <w:t> 标签内容 -->
<w:t>WHERE 学生.所在系 = @系名;</w:t>

<!-- 插GO段：构造新的 <w:p> 段落元素 -->
<w:p>
  <w:r><w:t>GO</w:t></w:r>
</w:p>

打包：

python pack.py unpacked/ 报告.docx

必须是ZIP_DEFLATED压缩，否则Word打不开。验证无误后直接发回微信。

Scenario

Completed a full document editing workflow entirely on mobile: received a database lab report that needed formatting fixes, used Claude Code to edit .docx XML directly through two rounds of iteration, reaching submission standard.

The .docx Secret

A .docx file is essentially a ZIP archive containing XML files. Unzip → edit XML → rezip. No Word needed.

Workflow

  1. python unpack.py report.docx unpacked/
  2. Edit word/document.xml — fix SQL formatting (GO placement, missing semicolons, USE/GO pairs)
  3. python pack.py unpacked/ report.docx
  4. Send back via cc-connect

Toolchain

  • Claude Code CLI: Analyzes XML, identifies SQL issues, generates fixes
  • Python scripts: unpack.py / pack.py for .docx ↔ XML conversion
  • cc-connect: Bridges phone and WeChat for file transfer

Verdict

Mobile AI document editing is completely viable. The entire flow — receive, edit, package, send — takes under 10 minutes without ever opening Word.

Applicable to: lab reports, course assignments, club documents, internship reports — any standardized .docx formatting task.
