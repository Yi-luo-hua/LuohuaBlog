不用上B站也可以看弹幕Watch Danmaku Without Bilibili

2025-02-22 800 字 632 阅读 约3 分钟

介绍

一个可以在任何视频网站上加载弹幕的浏览器扩展。

来自 Mr-Quin 大佬的分享（名称是 danmaku-anywhere）

仓库地址：Mr-Quin/danmaku-anywhere

项目配置比较简单，对于像我这种没钱又想要弹幕的比较合适。

B站可以跟随大佬视频学习配置（B站名称：磷化镓）

教程

本次教程以磷化镓大佬的视频为主，用Edge浏览器和AGE动漫网。

部分操作需要科学上网。

AGE动漫网：AGE动漫

下载插件

点击Mr-Quin大佬的danmaku-anywhere仓库拉到最下面，点击商店安装，然后下载插件（Edge浏览器下载提示的那个）。右上角出现扩展即安装成功。

开始配置

打开AGE动漫网，选择一个想看的动漫，点进去播放视频。

右键点击统计信息，复制视频网址。

然后在一个新的页面输入刚刚复制的网址打开。

打开插件：

按步骤进行配置，选择需要的弹幕。

效果展示

配置完成后，即可在AGE动漫网等第三方视频网站上看到B站弹幕。

对于不想开哔哩哔哩会员又想看弹幕的值得一试！

Introduction

A browser extension that loads danmaku on any video site, shared by Mr-Quin.

Repo: Mr-Quin/danmaku-anywhere

Simple to set up, great for those who want danmaku without paying for Bilibili membership.

Tutorial

Using Edge browser and AGE anime site as example.

Install the Extension

Go to the danmaku-anywhere repo, click the store install link, and download the extension for Edge.

Configuration

Open AGE anime site, pick an anime, right-click for video info, copy the video URL, then configure the extension step by step.

Result

Now you can enjoy Bilibili-style danmaku on any video site.
