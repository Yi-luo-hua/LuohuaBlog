Building a Blog with GitHub Pages

Preparation — Register GitHub

Open github.com and sign up with your email.

STEP1 — Fork a Template

Open mzlogin.github.io to see the blog template. Click Fork, then Create a new fork. After forking, visit your-username.github.io in your browser.

STEP2 — Configure Your Blog

Delete CNAME File

This file is related to custom domains. Remove if not needed.

Edit _config.yml

Open and modify the configuration file to personalize your blog.

Set Up Comment System (giscus)

Visit giscus.app, follow the steps, install the giscus GitHub App, and configure your repository.

Google Analytics

Set up at analytics.google.com and add your tracking ID.
