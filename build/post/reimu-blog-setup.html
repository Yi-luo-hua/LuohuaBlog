Reimu主题博客搭建笔记——Hexo新主题从零到部署Building a Blog with Reimu Theme — Hexo Theme Migration Guide

2026-05-10 3800 字 628 阅读 约15 分钟

本文记录了从零搭建一个全新Hexo博客的完整过程——使用拔剑Sketon开发的博丽灵梦风格Reimu主题，从初始化项目、配置主题、文章迁移、标签适配，到Vercel部署上线的全部踩坑记录。如果你也想换个新主题，这篇文章应该能帮你省不少时间。

为什么换主题？

Butterfly是一套非常成熟的Hexo主题，功能齐全。但在浏览D-Sketon（拔剑Sketon）的博客时，被Reimu主题的简洁东方风设计吸引：

亮点 说明
视觉风格 灵梦主题配色 + 太极图标动画
交互体验 AOS滚动动画 + PJAX无刷新加载
内置功能 照片墙、标签页、友链卡片、热力图
兼容性 暗色模式、响应式布局、多语言支持
性能 比Butterfly更轻量，风格更现代

搭建过程

1. 初始化项目

在D盘新建blog1目录：

cd D:/blog1
npx hexo init .
npm install hexo-theme-reimu

_config.yml中设置theme: reimu，同时配置站点信息：

title: 桃之夭夭の花园
author: 桃之夭夭
language: zh-CN

Reimu的配置文件是_config.reimu.yml（不是Butterfly的_config.butterfly.yml）。配置项包括导航菜单、打字机副标题、社交链接、侧边栏、i18n等。

2. 核心配置

从原博客复制了头像、社交链接等信息，重点配置了以下部分：

打字机副标题：

subtitle:
  typing:
    enable: true
    strings:
      - 学无止境，持之以恒
      - 千里之行，始于足下
    loop: true

社交链接（GitHub + B站 + 邮箱）：

social:
  github: https://github.com/bistutzyy
  bilibili: https://space.bilibili.com/1061280173
  email: mailto:173236231@qq.com

侧边栏： 只保留个人信息和标签云，去掉了分类、归档、最新文章。

导航菜单： 首页、归档、关于、友链四个入口。

3. 文章迁移

从原博客复制了14篇文章。但这里遇到了第一个大问题——Butterfly标签和Reimu标签互不兼容。

4. 关于页与友链页

关于页写入了个人介绍和GitHub贡献表：
- 个人简介 + 博客介绍
- GitHub贡献热力图（使用ghchart.rshah.org服务）
- 建站日期、技术栈

友链页加入原博客bistutzyy.github.io作为友链，命名为「桃之夭夭第一章」。

5. 部署到Vercel

在GitHub新建仓库bistutzyy/blog1-reimu，推送代码。然后在Vercel导入该仓库。

Vercel默认自动识别Hexo项目，构建命令为hexo generate，输出目录为public。但需要注意：

注意事项 说明
配置文件 需创建 vercel.json
package-lock.json Windows版在Vercel Linux环境可能冲突，建议 .gitignore 忽略
Node版本 需在 package.json 中设置 "engines": { "node": "24.x" }

遇到的问题与解决

问题一：Butterfly标签完全不兼容

现象： 复制过来的文章大量使用note、span、folding等Butterfly标签，生成时报unknown block tag错误。

原因： Reimu有自己的标签体系（alertBlockquote、details、gallery、tabs等），和Butterfly完全不兼容。

解决： 批量替换标签：

Butterfly Reimu
note alertBlockquote
folding details
span/p <span class="c-color">
label badge（需自定义）
tabs tabs（Reimu原生，语法相同）
gallery gallery（需重写）

对于Reimu没有的标签，在项目的scripts/目录下创建自定义标签脚本。所有自定义标签最后合并到scripts/tags.js。

问题二：照片墙JS代码泄漏到页面

现象： Vercel部署后，文章标题下方出现大段JavaScript代码文本。

原因： Reimu原版gallery标签会生成内联<script>实现photoWall效果。在Vercel构建环境中，这些内联JS被错误暴露为可见文本。

解决： 将gallery标签重写为纯CSS瀑布流，使用columns实现真瀑布流，每张图保持原始比例，不裁切。

问题三：轮播图在Reimu中完全无法使用

现象： Butterfly的carousel标签依赖carousel-touch.js和transform-style: preserve-3d，与Reimu的CSS布局冲突，3D旋转失效。

尝试过程：

尝试 方案 结果
一 保留 carousel-touch.js，修复3D变换 图片大小不一，旋转方向错乱
二 纯CSS scroll-snap滑动画廊 图片过大，毫无新意
三 自定义CSS展示型轮播，淡入淡出 竖屏图片显示不全，人脸被裁

最终方案： 放弃轮播图，改用gallery瀑布流直接展示所有图片。

轮播图是Butterfly和Reimu之间最深层的架构冲突——Butterfly的3D carousel依赖特定的CSS transform环境和外部JS，而Reimu的布局完全不兼容。与其勉强修复，不如使用主题原生的gallery。

问题四：中英双语切换始终无法生效

现象： 配置language: [zh-CN, en]并在source/en/_posts/下放置英文翻译，切换语言后文章正文仍是中文。

原因（核心）： 经过反复测试（Hexo 7.3.0、8.1.2、安装hexo-generator-i18n插件），确认Hexo不会自动扫描source/en/_posts/目录。source/en/只对页面（about、friend）生效，Post不受支持。

这是本次搭建中耗时最长（超过3小时）、尝试方案最多（4种）、最终也未能完美解决的问题。核心原因是Hexo框架本身不提供文章级多语言目录扫描，而Vercel又限制了运行时对node_modules的修改。

问题五：Vercel构建反复失败

现象： 推送代码后Vercel构建持续报错Nunjucks Error: unknown block tag，且每次错误都不同。

原因链：
1. 项目scripts/目录在清理过程中被误删，导致自定义标签丢失
2. hexo-butterfly-tag-plugins-plus在Node 24 + Vercel环境存在兼容问题
3. 文章中的标签语法示例被Hexo的Nunjucks解析器当作真实标签处理

解决步骤：
1. 将所有自定义标签合并到scripts/tags.js中统一管理
2. 保留hexo-butterfly-tag-plugins-plus依赖
3. 文章中涉及标签语法的部分全部用文字描述替代，避免被Nunjucks误解析
4. 在package.json中设置engines.node: "24.x"
5. 创建vercel.json指定构建命令和输出目录

这个问题的根本教训是：绝对不要在Hexo文章正文中直接写tag语法。Hexo的Nunjucks解析器在Markdown渲染前运行，代码块和行内代码都挡不住它。

问题六：封面图与轮播图的后续处理

封面图问题： Reimu的post.ejs会自动给没有cover字段的文章分配随机封面或使用主题banner。

解决： 用CSS暴力方案：.post-cover { display: none }。文章顶部banner设置cover为空值。

轮播图： 用gallery瀑布流替代，彻底移除了Butterfly carousel的所有依赖。

自定义标签实现

Reimu缺少的标签，在项目的scripts/tags.js中自定义。关键规则：Hexo会优先加载项目scripts/目录下的脚本，加载顺序晚于主题脚本。因此项目级标签可以覆盖同名主题标签。

badge标签（替代Butterfly的label）、timeline标签（自定义实现）、blockquote标签（带作者署名）。

配套CSS在source/css/tag-styles.css中定义，并通过reimu的injector.head_begin注入。

Why Switch Themes?

While browsing D-Sketon's blog, I was drawn to the Reimu theme's clean Eastern aesthetic — Reimu color scheme, yin-yang icon animation, AOS scroll effects, PJAX loading, photo walls, and dark mode.

Setup Process

Initialize

cd D:/blog1
npx hexo init .
npm install hexo-theme-reimu

Configure _config.yml with theme: reimu and use _config.reimu.yml for theme settings.

Migration Issues

Butterfly tags are completely incompatible with Reimu. Had to batch-replace: note → alertBlockquote, folding → details, span → CSS classes, label → custom badge tag.

Photo wall JS leaked — rewrote gallery tag with pure CSS columns waterfall.

Carousel completely broken — 3D carousel dependencies conflict with Reimu's CSS. Gave up and used gallery instead.

i18n article switching never worked — Hexo doesn't scan source/en/_posts/ for posts. This is a framework limitation. Spent 3+ hours on this, eventually gave up and kept the blog monolingual.

Vercel builds kept failing — Nunjucks was parsing tag syntax examples in article text as real tags. Lesson: never write raw tag syntax in Hexo post content.

Final Result

Successfully deployed at blog1-reimu.vercel.app with 14 articles migrated, custom tag scripts, and CSS gallery fallback.
