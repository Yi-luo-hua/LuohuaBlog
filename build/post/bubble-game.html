第一章 需求分析

本次程序设计实践所做的实验项目主要是通过开发工具和Jar指令运行泡泡糖项目，体验泡泡糖项目的显示、消除、移动和积分等业务功能。

1.1 项目设计思路

要设计出一款合格甚至优秀的游戏，在项目设计方面应该围绕游戏的可玩性、界面的可视性两方面出发。

1.1.1 可玩性

以泡泡糖为例，可玩性体现在它的上手简单（只需要点击相同的泡泡糖便可消除），但复杂的运行逻辑又使它的形式十分丰富，同时加入的关卡设计也让这个游戏更符合当下青年想要挑战的心理。

消除设计思路： 点击屏幕上任意一个"泡泡糖"，与之相连的同颜色泡泡糖也会一并消除。因此在写消除方面的代码时，需要找到所有靠近点击目标的同色样式，需要反复利用循环来完成设计。

关卡设计和积分奖励思路： 通过计算每局游戏的得分，来判断玩家是否能够通过关卡。同时在每次通关时还会给予玩家一定的通关积分奖励。

1.1.2 可视性

单一的游戏展示界面会让玩家很快感受到无聊，因此为泡泡糖的主界面设计了不同的主题风格，切换主题的方式也相当简便。

1.2 玩家分析

设计一款游戏首先要明确定位玩家群体。以《消灭泡泡糖》为例，该游戏是为了做出一个耐玩有趣的休闲类消除小游戏，供玩家娱乐消遣：

  • 随机泡泡糖——完成每一关挑战后，系统自动补全随机颜色的泡泡糖
  • 主题切换功能——玩家可选择不同主题，增强游戏个性化元素
  • 目标分数显示——玩家可清楚看到当前分数与目标分数
  • 额外奖励积分——无可消灭泡泡糖后判断剩余泡泡糖的奖励机制

public enum StarType {

    private int value = 0;
    private StarType(int value) { this.value = value; }
    public int value() { return this.value; }
    public static StarType valueOf(int value) {
        switch(value) {
            case 0: return BLUE;
            case 1: return GREEN;
            case 2: return YELLOW;
            case 3: return RED;
            case 4: return PURPLE;

        }
    }

创建Label控件点击事件处理类，实现EventHandler接口。点击界面上任意泡泡糖，界面实现消除泡泡糖操作：

class StartEventHandler implements EventHandler<MouseEvent> {
    private StarService starService = null;
    public StartEventHandler(StarService starService) {
        this.starService = starService;
    }
    @Override
    public void handle(MouseEvent event) {
        Label starFrame = (Label)event.getTarget();
        Star base = StarFormUtils.convert(starFrame);
        StarList starlist = this.starService.tobeClearedStars(base, mCurretStars);
        if (starlist == null || starlist.size() == 0) return;
        for(int i = 0; i < starlist.size(); i++) {
            Star star = starlist.get(i);
            Label lable = StarFormUtils.findFrame(star, mStarForm);
            StarAnimation.clearStarLable(mStarForm, lable);
            mCurretStars.setNull(star.getPosition().getRow(), star.getPosition().getColumn());
        }
    }
}

第五章 泡泡糖的移动

5.1 移动垂直方向的泡泡糖

交换两个泡泡糖：

public static void swap(Star preStar, Star nextStar) {
    // 交换位置
    Position tempPos = new Position(preStar.getPosition().getRow(), preStar.getPosition().getColumn());
    preStar.getPosition().setRow(nextStar.getPosition().getRow());
    preStar.getPosition().setColumn(nextStar.getPosition().getColumn());
    nextStar.getPosition().setRow(tempPos.getRow());
    nextStar.getPosition().setColumn(tempPos.getColumn());
    // 交换类型
    StarType tempType = preStar.getType();
    preStar.setType(nextStar.getType());
    nextStar.setType(tempType);
}

排序算法（按行号升序冒泡排序）：

public static void sort(StarList starList) {
    for (int i = 0; i < starList.size() - 1; i++) {
        for (int j = 0; j < starList.size() - i - 1; j++) {
            Star preStar = starList.get(j);
            Star nextStar = starList.get(j + 1);
            if (preStar.getPosition().getRow() > nextStar.getPosition().getRow()) {
                swap(preStar, nextStar);
            }
        }
    }
}

获取垂直方向待移动泡泡糖（多列版）：

通过对"待消除泡泡糖"按列分组，计算每列的下落跨度，生成MovedStar列表：

public StarList getYMovedStars(StarList clearStars, StarList currentStarList) {
    StarList movedStars = new StarList();
    Map<Integer, StarList> groupStars = StarsUtil.group(clearStars);
    Iterator<Integer> keys = groupStars.keySet().iterator();
    while (keys.hasNext()) {
        int column = keys.next();
        StarList starList = groupStars.get(column);
        int startPosition = starList.lastElement().getPosition().getRow();
        int span = 0;
        for (int row = startPosition; row >= 0; row--) {
            Star star = currentStarList.lookup(row, column);
            if (star == null) break;
            if (clearStars.existed(star)) { span++; }
            else {
                MovedStar movedStar = new MovedStar(
                    star.getPosition(), star.getType(),
                    new Position(row + span, column));
                movedStars.add(movedStar);
            }
        }
    }
    return movedStars;
}

第八章 项目实践的问题与解答（Q&A）

问题 解答
构造函数的作用？ 初始化类中的重要成员变量，可多次重载，默认具有零参构造函数
Math.random的作用？ 返回[0,1)小数，乘以极限定上限、加初始值定下限。例：(int)(Math.random()*8)+3 产生3~10
递归函数的运用？ lookupByPath查找四周同色泡泡糖，调用点=四周存在同色，退出点=四周无同色
何时使用继承？ (a)修改父类函数（StarList→ArrayList）(b)获取父类功能（继承Application）(c)属性扩展（MovedStar→Star）
接口的作用？ 定标准 + 解耦合。StarService隔离界面与业务，实现多人并行开发
集合泛型的作用？ 规范集合数据类型，保证类型一致，自定义类也可配套泛型
值传递 vs 引用传递？ 八种原始类型按值传递；对象/接口/数组按引用传递，多个变量指代同一内存

第九章 实践项目总结

9.1 递归函数的作用及注意点

递归函数核心为lookupByPath函数，以被点击泡泡糖为基准，向四个方向逐层查找同色泡泡糖。使用时需注意：必须明确"调用点"与"退出点"，防止死循环；需控制递归范围，仅在矩阵内查找相连同色泡泡糖。

9.2 枚举类型的作用及应用

  • 提升代码可读性——将无意义的数值转化为有业务含义的常量，降低软件后期维护成本
  • 保障类型安全——枚举取值为预定义固定常量，无法随意创建新实例

Bubble Pop Game — A Java Project

A JavaFX-based casual elimination game featuring 10×10 bubble grids, recursive connected-component elimination, gravity mechanics, level progression, and theme switching.

Repo: bistutzyy/Bubble

Architecture

  • Model: Star (position, color/type), MovedStar (extends Star with target position), StarList
  • View: JavaFX FXML layouts with skin1/skin2 theme switching
  • Controller: MainForm with event handlers
  • Service: StarService interface decouples UI from business logic

Core Mechanics

Elimination: Click any bubble → recursive BFS in 4 directions finds all connected same-color bubbles → animate removal

Gravity: After elimination, bubbles fall vertically (bubble sort by row, group by column, compute span)

Horizontal Shift: Empty columns trigger left-shift of remaining columns

Scoring: Elimination score = n² × base; Bonus = reward_base × (limit - remaining)²; Level progression with dynamic score thresholds

Key Technical Learnings

  • Recursive functions (connected-component search with clear entry/exit points)
  • Enum types for type safety and readability
  • Interface-based decoupling for parallel development
  • Java generics for type-safe collections
  • Pass-by-value vs pass-by-reference in Java
  • Inheritance for property extension (MovedStar extends Star)
  • JavaFX UI development and Jar packaging
