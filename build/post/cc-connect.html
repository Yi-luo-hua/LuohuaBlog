cc-connect 手机电脑双端连通cc-connect — Seamless Phone-PC Workflow

2026-05-14 1800 字 312 阅读 约7 分钟

用手机指挥电脑上的Claude Code写代码、发文件、改配置，全程无需碰键盘。这篇教程记录我如何通过cc-connect把Claude Code接入微信，实现双端联动。

本文所有操作均在Windows 11 + Node.js 22环境下完成，微信端使用个人微信（ilink通道）。

一、什么是cc-connect？

cc-connect是一个开源桥接工具，将本地AI编程助手（Claude Code、Cursor、Gemini CLI等）接入微信、飞书、Telegram等聊天平台，让你随时随地从手机远程操控AI Agent。

项目地址：https://github.com/chenhg5/cc-connect

平台 状态 平台 状态
飞书/Lark 稳定 微信个人号 Beta
Telegram 稳定 企业微信 稳定
钉钉 稳定 QQ 稳定
Slack 稳定 LINE 稳定
Discord 稳定

核心能力概括：

  • 手机微信直接与Claude Code对话
  • 支持图片/文件/语音发送到电脑
  • 电脑端文件可回传到微信聊天
  • 斜杠命令操控Agent（/mode、/new、/stop等）
  • 无需公网IP，扫码即连

二、安装配置

Step 1 — 安装Beta版

微信个人号渠道仅在Beta版中可用。必须用@beta标签安装：

npm install -g cc-connect@beta

安装完成后验证：

cc-connect --version

Step 2 — 初始化配置

cc-connect init

这会在~/.cc-connect/下生成config.toml。关键配置如下：

# cc-connect configuration
language = "zh"
attachment_send = "on"       # 文件回传总开关

[display]
thinking_messages = false
tool_messages = false

[[projects]]
name = "default"
[projects.agent]
type = "claudecode"
[projects.agent.options]
work_dir = "C:/Users/lenovo"
mode = "default"

[[projects.platforms]]
type = "weixin"

Step 3 — 微信扫码绑定

cc-connect weixin setup --project default

终端会弹出二维码 → 用微信扫码确认 → token自动写入配置。无需手动填token。

三、启动与使用

cc-connect

启动后，打开微信向机器人发消息即可交互。我把工作目录定位在C:/Users/lenovo，这样Claude Code的所有能力（skills、memory、项目上下文）都能在手机上调用。

四、微信端斜杠命令

在微信对话框直接输入以下命令控制Agent：

命令 作用
/new [name] 开启新会话
/list 列出所有会话
/switch <id> 切换会话
/current 查看当前会话
/history [n] 查看历史消息
/mode default 标准权限模式
/mode plan 规划模式
/mode yolo 自动执行模式
/stop 停止当前任务
/quiet 开关进度消息
/dir <path> 切换工作目录
/model 切换AI模型
/allow <tool> 预授权工具
/memory 管理长期记忆
/cron add 添加定时任务

五、文件互传

手机 → 电脑

直接在微信发文件/图片/语音，cc-connect自动保存到.cc-connect/attachments/并交给Claude Code处理。

电脑 → 手机

在终端使用cc-connect send命令将文件发回微信：

# 发送文件
cc-connect send --file "C:/Users/lenovo/Desktop/report_final.docx"

# 发送图片
cc-connect send --image "C:/path/to/screenshot.png"

# 同时发送文件+图片
cc-connect send --file "report.pdf" --image "chart.png"

发文件用绝对路径最稳妥，避免路径解析问题。

六、语音消息

cc-connect还支持语音互转。在config.toml中添加speech配置即可使用Groq的whisper-large-v3模型进行语音转文字。

  • 微信语音自动转文字发给Claude Code
  • Claude Code回复可选转语音播报
  • 需要安装ffmpeg依赖

七、总结

现在我不在家也能用手机指挥电脑上的Claude Code：

  • 写博客、改代码、搜文件
  • 电脑生成的文件一键发到手机
  • 开车时用语音下指令
  • 定时任务自动运行

整套配置不超过30分钟，强烈推荐给所有用Claude Code的朋友。

常见问题FAQ

问题 解答
微信收不到机器人消息？ 检查cc-connect服务是否在运行，以及token是否过期（重新扫码即可）
文件发送失败？ 确认attachment_send = "on"已设置，并使用Beta版cc-connect@beta
语音转文字不工作？ 需要安装ffmpeg并配置Groq API key，Groq提供免费额度
可以多台手机同时接入吗？ 可以，多个项目在配置中分不同的[[projects]]即可

What is cc-connect?

cc-connect is an open-source bridge that connects local AI coding assistants (Claude Code, Cursor, Gemini CLI, etc.) to chat platforms like WeChat, Lark, and Telegram.

Repo: https://github.com/chenhg5/cc-connect

Installation

npm install -g cc-connect@beta
cc-connect init
cc-connect weixin setup --project default

Usage

cc-connect

Then send messages to the bot on WeChat. Slash commands like /new, /stop, /mode, /switch control the agent.

File Transfer

  • Phone → PC: Send files/images/voice directly in WeChat
  • PC → Phone: cc-connect send --file "path/to/file"

Voice Messages

Configure Groq's whisper-large-v3 in config.toml for speech-to-text.

Summary

With cc-connect, I can command Claude Code on my PC from anywhere via WeChat — write blogs, edit code, search files, and get results sent back to my phone. The entire setup takes under 30 minutes.
