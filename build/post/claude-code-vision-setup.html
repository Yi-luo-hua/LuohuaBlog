Claude Code + DeepSeek + 千问VL：零成本为国产大模型装上"眼睛Claude Code + DeepSeek + Qwen VL — Zero-Cost Vision for Chinese LLMs

一句话总结：Claude Code接入DeepSeek V4 Pro后，编程能力爆表但不会看图。通过一个100行的vision.js脚本+阿里云百炼千问VL模型，不花一分钱就能补上这个短板。

这套方案已经在我自己的电脑上跑通了——截图发过去，AI自动识别，全程无需手动敲命令。

一、背景：为什么需要"眼睛"？

阶段 说明
接入DeepSeek Claude Code通过自定义API Base URL，接入DeepSeek V4 Pro
发现盲区 截图发过去AI一脸懵——DeepSeek是纯文本模型，不具备视觉能力
补上眼睛 千问VL当"翻译官"：图片→文字→交给DeepSeek，新用户100万Token免费

二、方案原理

核心思路：图片不进DeepSeek，而是绕道千问VL先转成文字，再把文字交给DeepSeek处理。整个过程对用户透明——你只管发图，AI自动处理。

流程：用户发图片 → Claude Code → CLAUDE.md触发规则 → vision.js脚本 → 读取图片Base64 → 千问VL模型API → 返回文字描述 → DeepSeek V4 Pro分析回复

三、完整配置步骤

步骤1：获取千问API Key

  1. 打开阿里云百炼控制台
  2. 登录阿里云账号（没有就先注册）
  3. 在控制台找到API Key管理，创建一个新Key
  4. 复制生成的Key

新用户赠送100万Token免费额度，有效期90天。日常看图每次消耗约500-1000 Token，够用上千次。

步骤2：克隆vision.js脚本

教程来源：GitHub开源项目 asuojun/claude-vision-skill

git clone https://github.com/asuojun/claude-vision-skill.git D:/deepseek-vision
cd D:/deepseek-vision
npm install dotenv

步骤3：配置API Key和模型

打开D:/deepseek-vision/.env，填写：

DASHSCOPE_API_KEY=你的真实Key

vision.js中的模型已预设为qwen-vl-max（性价比最高的VL模型）：

模型 输入价格 输出价格 定位
qwen-vl-max 1.6元/百万Token 4元/百万Token 纯视觉理解，日常看图首选
qwen3.5-omni-plus ~0.8元/百万Token ~4.8元/百万Token 全模态（视觉+音频）

步骤4：配置CLAUDE.md

在项目根目录创建或修改CLAUDE.md，告诉Claude Code何时调用vision.js：

# 识图能力

你的底层模型不具备原生识图能力。遇到图片时，不要用Read工具，改用vision.js：

node /d/deepseek-vision/vision.js "<图片路径>" "用中文描述这张图片"

注意：vision.js的路径要写绝对路径，否则Claude Code可能找不到。

步骤5：测试

发一张截图给Claude Code，它应该自动执行：

node /d/deepseek-vision/vision.js "D:/截图专用/xxx.png" "用中文描述这张图片"

五、常见问题

问题 解答
vision.js报"Incorrect API key" dotenv包未安装，运行 npm install dotenv
图片路径有空格？ 用双引号包裹路径
网络图片能用吗？ 支持，使用 --url 参数
能换其他vision模型？ 修改 .env 和 vision.js 中的 BASE_URL 与 MODEL
