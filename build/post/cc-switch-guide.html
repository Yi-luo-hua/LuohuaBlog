CC Switch —— 一站管理AI CLI工具的瑞士军刀CC Switch — The Swiss Army Knife for AI CLI Tools

2026-05-13 2000 字 478 阅读 约8 分钟

如果你同时使用Claude Code、Codex、Gemini CLI等多个AI编程CLI工具，你一定经历过这些痛苦：改配置文件切来切去、API Key记不住、供应商地址找半天、MCP服务器每个工具配一遍……

CC Switch就是来解决这些问题的。它由GitHub用户farion1231开发，开源免费（MIT协议），截止2026年初已斩获5.4万Star。

一、CC Switch是什么？

CC Switch是一款基于Tauri 2构建的跨平台桌面应用，核心定位是AI CLI工具的全能配置管理助手。

简单说：它是一个可视化的配置面板，让你不用再手动编辑JSON/TOML/.env文件来切换AI模型供应商。

支持的应用：Claude Code · Codex (OpenAI) · Gemini CLI · OpenCode · OpenClaw · Hermes Agent

二、核心功能一览

1. 多供应商一键切换

内置50+预设供应商，覆盖几乎所有主流AI API平台：

分类 供应商
官方 Anthropic、OpenAI、Google Gemini
国产 DeepSeek、Kimi、智谱GLM、Moonshot、百川、Qwen
聚合平台 OpenRouter、SiliconFlow、AIHubMix、NVIDIA NIM
云服务 AWS Bedrock、Azure、Google Cloud

支持Anthropic Messages原生格式和OpenAI Chat Completions兼容格式，无论供应商用哪种API格式都能适配。

切换供应商只需在CC Switch中选择对应配置，所有关联的CLI工具即时生效，无需重启终端。

2. MCP服务器统一管理

特性 说明
统一面板 单一面板管理所有应用的MCP配置
多协议 支持 stdio / http / sse 三种传输类型
预设模板 fetch、context7、sequential-thinking 等开箱即用
智能校验 冲突检测与字段校验
跨应用同步 Claude Code / Codex / Gemini CLI / OpenCode 双向同步

不用再每个工具重复配置一遍MCP了，CC Switch自动帮你做双向同步。

3. Skills管理

功能 说明
自动发现 扫描GitHub热门Claude Skills仓库
一键操作 安装 / 卸载 / 更新Skills，支持批量
本地导入 支持从本地ZIP安装
预设仓库 内置 baoyu-skills 等精选源
版本管理 版本回滚，随时切回旧版

相当于一个Skills的应用商店，不用手动下载解压拷贝了。

4. 本地路由 & 故障转移

内置了一个高性能HTTP本地代理，提供：

能力 说明
请求监控 实时查看API请求/响应
自动故障转移 主供应商挂掉自动切备用
熔断器 连续失败达阈值自动暂停
健康监控 供应商延迟可视化面板
用量统计 Token消耗、成本追踪、缓存命中率

还有一个Claude Rectifier功能——修复第三方API网关的thinking block签名格式问题，让DeepSeek等国产模型在Claude Code中也能完整输出思考过程。

5. 更多实用功能

  • 系统托盘：托盘秒切供应商，不用打开主窗口
  • 会话管理：浏览、搜索、恢复、删除跨应用对话历史
  • 云同步：WebDAV / Dropbox / OneDrive / iCloud 多设备同步配置
  • 深链接：ccswitch:// 协议一键导入供应商/MCP配置
  • Prompts管理：Markdown实时编辑预览，跨应用同步CLAUDE.md
  • 三语界面：中文 / English / 日本語

三、安装方式

Windows：前往Releases页面下载最新MSI安装包或Portable免安装版。

macOS：

brew tap farion1231/ccswitch
brew install --cask cc-switch

Linux：

# Arch Linux (AUR)
paru -S cc-switch-bin

# Debian/Ubuntu
wget https://github.com/farion1231/cc-switch/releases/latest/download/CC-Switch-latest-Linux.deb
sudo dpkg -i CC-Switch-latest-Linux.deb

四、实际使用体验

配置效率

以前换一个供应商要改Claude Code的settings.json，再改Codex的TOML，还要改.env……现在在CC Switch里选一下，所有工具自动生效。

MCP不再重复配置

MCP服务器在CC Switch里配置一次，Claude Code和Codex都能用，新增工具时也只需要加一次。

Skills安装超方便

之前装Skills要手动clone或者下载ZIP解压到.claude/skills/目录，现在在CC Switch里浏览 → 点击安装 → 搞定。

故障转移保住效率

用DeepSeek的时候偶尔会遇到API限流，本地路由自动切到备用供应商，基本无感切换。

五、技术架构

层 技术栈
前端 React 18 + TypeScript + Vite + TailwindCSS + shadcn/ui + TanStack Query v5
后端 Rust（Tauri 2）
存储 SQLite
跨平台 Windows / macOS / Linux（x64 + arm64）

Tauri 2让它体积小巧（相比Electron应用），同时Rust保证了本地代理的性能。

六、总结

如果你每天和Claude Code/Codex/Gemini CLI打交道，CC Switch是必装工具。它把"改配置"这件事从5分钟压缩到5秒，加上MCP和Skills管理、本地路由这些锦上添花的功能，完全可以取代手动管理配置文件的原始方式。

项目地址：https://github.com/farion1231/cc-switch

What is CC Switch?

A Tauri 2-based cross-platform desktop app for managing all your AI CLI tools — Claude Code, Codex, Gemini CLI — from one panel. 50+ built-in providers, one-click switching, no more manual config editing.

Core Features

Provider Switching

50+ preset providers (Anthropic, OpenAI, DeepSeek, Kimi, OpenRouter, etc.) with instant switching across all connected CLI tools.

MCP Management

Configure MCP servers once, sync across Claude Code, Codex, and Gemini CLI automatically.

Skills Management

Browse, install, update, and rollback Claude Code Skills from GitHub — like an app store for Skills.

Local Routing & Failover

Built-in HTTP proxy with request monitoring, automatic failover, circuit breaker, health monitoring, and usage statistics.

Installation

Available on Windows (MSI/Portable), macOS (Homebrew), and Linux (AUR/deb/rpm/AppImage).

Verdict

If you use multiple AI CLI tools daily, CC Switch is a must-have. It compresses config switching from 5 minutes to 5 seconds.
