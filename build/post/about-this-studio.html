这个创作屋是怎么来的

桃之夭夭の创作屋，不是一夜之间建成的。

它的前身是部署在 GitHub Pages 上的 Hexo 博客 bistutzyy.github.io，使用 Butterfly 主题，断断续续写了将近两年。后来还用 Reimu 主题在 Vercel 上搭了第二个站 blog1-reimu.vercel.app。两个博客各有所长，但管理起来越来越碎片化。

于是就有了这个创作屋——把分散的内容汇集到一处，用一个更自由的方式呈现。

Vibe Coding：用对话搭建网站

这个站点几乎全部由 Vibe Coding 方式构建。

所谓 Vibe Coding，是 Andrej Karpathy 在 2024 年提出的概念——你不再逐行写代码，而是用自然语言描述你想要的东西，AI 帮你生成、迭代、调试。你负责方向，AI 负责实现。

三个 AI 编程工具分工协作：

工具 负责部分
OpenAI Codex 主页整体设计——index.html 布局、侧边栏、渐变背景、交互动效
Cursor 碎片化设计——gallery 相册页、links 友链、message 留言墙等独立页面
Claude Code + DeepSeek V4 Pro 文章体系——build_content.py 构建脚本、21篇文章Markdown、CSS样式调优

辅助工具链：

工具 用途
千问 VL 模型 识图——截图→文字描述，补上 DeepSeek 的视觉盲区
cc-connect + 微信 手机远程操控电脑写代码、发文件
CC Switch 多 AI 供应商一键切换、Skills 统一管理
docx / pptx / pdf Skills 自动生成实验报告和幻灯片

整个过程就是：在微信上发一段需求 → AI 分析 → 生成代码 → 审查修改 → 提交。全程没有打开传统 IDE，甚至很多时候是在手机上完成的。

内容从哪里来

文章大部分从 bistutzyy.github.io 迁移过来，一共 21 篇，涵盖教程、项目记录、人物赏析、实验报告等。

碎语入口承接原博客的碎碎念内容，现在统一从主站首页导航站进入。

迁移过程中做了大量适配——原博客使用 Hexo + Butterfly 标签语法（note、span、label、timeline 等），迁移后全部转为标准 Markdown，去掉了封面图和装饰效果，保留了核心内容和配图。

技术特点：

  • 静态生成：Markdown 编写内容，Python 脚本一键构建为 HTML
  • 双语支持：每篇文章中英双语，页面级语言切换
  • 代码高亮：macOS 终端风格代码块，highlight.js 语法着色
  • 响应式：桌面端完整侧边栏，移动端自动折叠
  • 天气特效：右下角可切换雨天模式

写在最后

这个创作屋本身就是一个 Vibe Coding 的产物——用 AI 辅助，从想法到上线，一步步迭代成形。它不是完美的，但它是我想要的。

内容会继续更新，功能会继续完善。感谢来访。

How This Studio Came to Be

Taozhiyaoyao Studio wasn't built overnight.

It started as a Hexo blog on GitHub Pages (bistutzyy.github.io) and later a second site on Vercel with the Reimu theme. Both served well, but managing fragmented content across platforms became unwieldy. So I built this studio — a unified home for everything.

Built with Vibe Coding

This entire site was built through Vibe Coding — describing what I want in natural language and letting AI generate, iterate, and debug.

Three AI coding tools split the work:

Tool Responsibility
OpenAI Codex Main page design — layout, sidebar, gradients, animations
Cursor Fragment design — gallery, links, message board
Claude Code + DeepSeek V4 Pro Article system — build script, 21 Markdown articles, CSS

Supporting tools: Qwen VL for vision, cc-connect for mobile control, CC Switch for config, docx/pptx/pdf Skills for documents.

Content Migration

All 21 articles were migrated from the original Hexo blog, converted from Butterfly tag syntax to standard Markdown. Core content and images preserved, decorative effects stripped.

What's Inside

  • Home — Hero section + navigation
  • Archives — Timeline view by year
  • Articles — 21 bilingual long-form posts
  • Moments — Short-form updates
  • Gallery — Anime collection
  • Links — Friend links
  • Guestbook — Visitor messages

Built with Markdown + Python static generation, bilingual support, terminal-style code highlighting, responsive layout, and weather effects.

Final Words

This studio itself is a product of Vibe Coding — iterating from idea to launch with AI assistance. It's not perfect, but it's mine. More to come.
