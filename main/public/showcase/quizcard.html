02 · Features

四项核心能力

从输入到输出的全链路设计：AI 解析、双模式练习、统一设计语言、按用户隔离的数据持久化。

01

AI 智能识别

粘贴任意题目原文，AI 自动结构化为题干 + 选项 + 正确答案 + 解析。支持单选、多选、判断三种题型混合识别。

02

Deep + Quick 双模式

Deep 给完整解析与错题归纳，Quick 给 0.5 秒闪练训练手感。两套交互节奏一冷一热，对应理解与肌肉记忆两种学习需求。

03

Titanium Glow 3.0

钛金辉光设计系统：毛玻璃 + 全息边 + Nebula 进度条 + Pearlescent 渐变。同一套 token 跨网页与小程序两端复用。

04

多用户隔离

网页邮箱注册 / 小程序微信一键登录，账户隔离题库与练习记录。默认 AI 接口受限，自定义 API Key 后无限制。

03 · Mini Program

小程序完整设计

登录到设置共 9 个页面的 1:1 静态复刻。点击任意一张放大到全屏可滚动查看。

登录№ 01

微信一键登录 / 体验账号 / 用户协议入口。

卡片库№ 02

题库列表、统计、搜索、新建入口。

新建№ 03

粘贴 → AI 识别 → 预览调整三步流程。

练习设置№ 04

题数 / 顺序 / 范围 / 其他四组开关。

Deep 练习№ 05

题干 + 选项 + 解析卡，关注理解。

Quick 闪练№ 06

0.5 秒倒计时，关注手感与速度。

报告№ 07

正确率、用时、题型分布、错题回顾。

历史№ 08

按日期分组的练习记录与正确率环。

设置№ 09

账户、AI 接口、主题、清除数据。
